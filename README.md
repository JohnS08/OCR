# OCR сканированных PDF для Windows

Программа `ocr_scans.py` рекурсивно берёт PDF из `C:\СКАН` и создаёт PDF с теми же именами и структурой папок в `C:\СКАН\РЕЗУЛЬТАТ`. Исходная страница не перерисовывается: к ней добавляется **невидимый текстовый слой**. Поэтому расположение объектов, рисунки, формулы, линии таблиц, цвета и разрешение визуально остаются как в исходном скане.

> **Важно:** итоговый PDF выглядит как оригинал. Распознанный текст можно искать, выделять и копировать. Ячейки таблиц получают текст на своих исходных координатах; PDF не преобразуется в отдельную семантическую таблицу, поскольку выбранный выходной формат должен сохранить исходную вёрстку.

## Что программа делает

| Объект на скане | Результат |
|---|---|
| Обычный русский и английский текст | Добавляется в невидимый, доступный для поиска и копирования текстовый слой. |
| Таблица | Текст ячеек распознаётся и остаётся привязанным к исходным координатам в PDF. Границы, фон и геометрия таблицы сохраняются графически. |
| Рисунок, схема, печать, фотография | Визуально остаётся исходной графикой. |
| Формула | Строка, похожая на формулу, не добавляется в текстовый слой и остаётся только графикой; запись появляется в `ocr.log`. |
| Слово с уверенностью ниже порога | Остаётся только графикой; координаты и оценка уверенности записываются в `ocr.log`. |

## Предварительные требования

Нужна 64-битная Windows 10, уже установленный Python **3.14** и права на установку программ. PyMuPDF публикует готовые пакеты для Windows и Python 3.10–3.14.[1] Tesseract требуется как отдельный OCR-движок, а язык выбирается по установленным файлам `traineddata`.[2] [3]

### 1. Установите Tesseract OCR

Откройте PowerShell **от имени администратора** и выполните:

```powershell
winget install -e --id UB-Mannheim.TesseractOCR
```

Если после установки команда `tesseract --version` не находится, закройте и снова откройте PowerShell. Если это не помогло, добавьте папку `C:\Program Files\Tesseract-OCR` в переменную среды `PATH` либо передавайте путь к `tesseract.exe` через параметр `--tesseract`.

### 2. Установите русский языковой файл

Английский язык обычно присутствует как `eng`. Для русского скачайте официальный файл [`rus.traineddata`](https://github.com/tesseract-ocr/tessdata/raw/main/rus.traineddata) и скопируйте его в папку:

```text
C:\Program Files\Tesseract-OCR\tessdata\
```

Подтвердите, что оба языка видны движку:

```powershell
tesseract --list-langs
```

В списке должны быть строки `eng` и `rus`.

### 3. Установите Python-зависимости

Скопируйте файлы этого проекта, например, в `C:\OCR-PDF`, затем откройте PowerShell в этой папке:

```powershell
cd C:\OCR-PDF
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Проверка перед обработкой

Создайте папку `C:\СКАН`, если её ещё нет, и проверьте окружение:

```powershell
.\.venv\Scripts\python.exe .\ocr_scans.py --check
```

При успехе программа покажет версию Tesseract, использованный шрифт и журнал проверки. Если Tesseract установлен в нестандартную папку, используйте, например:

```powershell
.\.venv\Scripts\python.exe .\ocr_scans.py --check --tesseract "D:\Apps\Tesseract-OCR\tesseract.exe"
```

## Обычный запуск

Поместите PDF в `C:\СКАН` и запустите:

```powershell
.\.venv\Scripts\python.exe .\ocr_scans.py --reset-log
```

Готовые документы появятся в `C:\СКАН\РЕЗУЛЬТАТ`; программа также создаст `C:\СКАН\РЕЗУЛЬТАТ\ocr.log`. Повторный запуск не перезаписывает существующие результаты. Чтобы обработать документы заново, примените `--overwrite`:

```powershell
.\.venv\Scripts\python.exe .\ocr_scans.py --overwrite --reset-log
```

## Основные параметры

| Параметр | Назначение | Значение по умолчанию |
|---|---|---|
| `--source` | Корневая папка с PDF. Вложенные папки также обрабатываются. | `C:\СКАН` |
| `--output` | Папка результатов. | `C:\СКАН\РЕЗУЛЬТАТ` |
| `--languages` | Языки Tesseract. | `rus+eng` |
| `--dpi` | Разрешение для OCR. При нечётком мелком тексте можно использовать 400. | `300` |
| `--confidence` | Минимальная уверенность слова. Меньшее значение повышает полноту, большее — осторожность. | `75` |
| `--psm` | Режим сегментации страницы Tesseract. | `3` |
| `--tesseract` | Полный путь к `tesseract.exe`, если его нет в `PATH`. | не задан |
| `--font` | TrueType-шрифт с кириллицей для текстового слоя. | сначала Arial, затем Calibri или Times New Roman |
| `--timeout` | Лимит OCR одной страницы в секундах. | `180` |
| `--overwrite` | Перезаписывает уже обработанные PDF. | выключен |
| `--reset-log` | Начинает новый файл `ocr.log`. | выключен |

## Настройка качества

Сначала обработайте 3–5 типичных файлов и проверьте поиск/копирование текста в результатах. Если плохое качество сканов создаёт много ошибочного текста, поднимите порог, например до 85:

```powershell
.\.venv\Scripts\python.exe .\ocr_scans.py --confidence 85 --overwrite --reset-log
```

Если на странице мелкий печатный текст, попробуйте 400 DPI. Это увеличит время обработки и потребление памяти:

```powershell
.\.venv\Scripts\python.exe .\ocr_scans.py --dpi 400 --overwrite
```

Для скана с одной текстовой колонкой иногда помогает режим сегментации 6:

```powershell
.\.venv\Scripts\python.exe .\ocr_scans.py --psm 6 --overwrite
```

## Как читать `ocr.log`

Журнал использует UTF-8. В нём фиксируются формулы (`ФОРМУЛА`), слова ниже порога (`НЕУВЕРЕННО`), успешные файлы (`ГОТОВО`) и ошибки (`ОШИБКА`). Для спорных слов записаны номер страницы, координаты на растровом изображении, исходный текст Tesseract и степень уверенности. Это позволяет быстро найти участки, которые остались графикой и требуют ручной проверки.

## Ограничения

Качество OCR зависит от исходного скана. Tesseract может ошибаться на размытом тексте, рукописных фрагментах, сложной многоколоночной вёрстке и редких шрифтах.[2] Программа намеренно использует консервативное правило: при сомнении она **не добавляет** текстовый слой к формуле или слову с низкой уверенностью, оставляя исходную графику без изменений. Не существует универсального автоматического критерия, который со 100% точностью отделяет формулы от коротких строк с буквами и символами; на реальных документах рекомендуются пробный прогон и при необходимости корректировка параметров `--confidence`, `--dpi` и `--psm`.
